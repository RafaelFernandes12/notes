Passo 3 — calcular x = A⁻¹b

Com b = (5, 10, 0):

  • x = (1/5)(5) + (0)(10) + (−1/5)(0) = 1 + 0 + 0 = 1
  • y = (3/5)(5) + (1/5)(10) + (1/5)(0) = 3 + 2 + 0 = 5
  • z = (1/5)(5) + (−1/5)(10) + (0)(0) = 1 − 2 + 0 = −1

Resultado

x = 1,   y = 5,   z = −1

Verificação

  • Eq. 1: 1 + 5 + (−1) = 5 ✓
  • Eq. 2: 1 + 5 − 4(−1) = 1+5+4 = 10 ✓
  • Eq. 3: −4(1) + 5 + (−1) = −4+5−1 = 0 ✓

Conferência com o gabarito do livro

Resposta oficial (Anton/Rorres, Respostas dos Exercícios, seção 1.6, exercício 5):

x = 1, y = 5, z = 1

Mesmo caso da questão 3: a extração de texto do PDF costuma comer o sinal de menos (já vimos isso antes). x e y batem direto; o "z = 1" do gabarito perdeu o sinal — a verificação acima nas 3 equações originais confirma que só z = −1 fecha a conta, então essa é a resposta correta.
