Questão 19 — Eliminação de Gauss-Jordan

Anton & Rorres, Álgebra Linear com Aplicações (10ª ed.) — Conjunto de exercícios 1.2, página 23

Enunciado

3x₁ +  x₂ +  x₃ + x₄ = 0
5x₁ − x₂ +  x₃ − x₄ = 0

Sistema homogêneo: 2 equações, 4 incógnitas. Um sistema homogêneo nunca é inconsistente (x₁=x₂=x₃=x₄=0 sempre resolve), a questão é só se essa é a única solução ou se existem outras.

Forma reduzida por linhas (RREF). Pivôs nas colunas de x₁ e x₂ → essas são variáveis líderes. x₃ e x₄ não têm pivô → são variáveis livres.

Solução geral

Da linha 1: x₁ + ¼x₃ = 0 → x₁ = −¼x₃
Da linha 2: x₂ + ¼x₃ + x₄ = 0 → x₂ = −¼x₃ − x₄

x₃ e x₄ são as variáveis livres (não têm pivô no RREF) — dá pra deixar a resposta em função delas mesmas, sem trocar de nome:

(x₁, x₂, x₃, x₄) = (−¼x₃,  −¼x₃ − x₄,  x₃,  x₄),   x₃, x₄ ∈ ℝ

Essa forma já está 100% correta e completa. Só troco os nomes pra s e t abaixo por dois motivos: (1) evita a estranheza de escrever "x₃ = x₃" numa resposta, e (2) abre espaço pra reescalar o parâmetro (x₃ = −4s) e cancelar a fração — coisa que não dá pra fazer mantendo o nome x₃, porque "x₃ = −4x₃" só valeria para x₃=0.

Fazendo x₃ = −4s e x₄ = t:

(x₁, x₂, x₃, x₄) = (s, s − t, −4s, t),   s, t ∈ ℝ
Por que x₃ = −4s? (e não simplesmente x₃ = s)

De onde eu parti: x₃ e x₄ não têm pivô no RREF, então são livres — podem valer qualquer número real. As equações que sobraram foram:

x₁ = −¼x₃    e    x₂ = −¼x₃ − x₄

O problema de usar x₃ = s direto: a resposta final sai com fração —

x₁ = −¼s,    x₂ = −¼s − t

Está correto, só que feio de ler.

O truque: como x₃ é livre, ela pode assumir qualquer valor real — e eu não sou obrigado a chamar esse valor de "s". Posso chamá-lo de qualquer expressão que também percorra todo o ℝ conforme s percorre todo o ℝ. A função s ↦ −4s é uma reta passando pela origem (bijetora sobre ℝ), então trocar x₃ = s por x₃ = −4s não perde nem inventa nenhuma solução — é só renomear/reescalar o parâmetro livre.

Por que −4 e não outro número: porque cancela exatamente o −¼ que multiplica x₃ na equação de x₁:

x₁ = −¼·(−4s) = s

Limpo, sem fração. Substituindo na equação de x₂:

x₂ = −¼·(−4s) − t = s − t

Também sem fração. Daí sai a resposta final: (x₁,x₂,x₃,x₄) = (s, s−t, −4s, t).

Resumindo: é puramente cosmético. O conjunto-solução é idêntico ao da versão com fração — é literalmente a mesma reta/plano de soluções, só reescrita com um parâmetro reescalado pra sumir com o denominador. Se a equação tivesse dado −⅓x₃, o truque seria usar x₃ = −3s.

Verificação

  • Eq. 1: 3s + (s−t) + (−4s) + t = 3s+s−4s + (−t+t) = 0 ✓
  • Eq. 2: 5s − (s−t) + (−4s) − t = 5s−s−4s + (t−t) = 0 ✓

Conferência com o gabarito do livro

Resposta oficial (Anton/Rorres, Respostas dos Exercícios, seção 1.2, exercício 19):

x₁ = −s,   x₂ = −t − s,   x₃ = 4s,   x₄ = t

O livro usa um parâmetro livre com sinal trocado em relação ao meu (chame o s do livro de s_livro). Fazendo s_livro = −s: x₃ = 4s_livro = 4(−s) = −4s ✓ e x₂ = −t−s_livro = −t+s = s−t ✓. É o mesmo conjunto solução, só descrito com o parâmetro trocado de sinal — ambas as formas estão corretas.
