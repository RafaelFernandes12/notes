Questão 3 — Resolvendo pela inversa da matriz de coeficientes

Anton & Rorres, Álgebra Linear com Aplicações (10ª ed.) — Conjunto de exercícios 1.6, página 65

Enunciado

 x₁ + 3x₂ +  x₃ =  4
2x₁ + 2x₂ +  x₃ = −1
2x₁ + 3x₂ +  x₃ =  3

Passo 3 — calcular x = A⁻¹b

Com b = (4, −1, 3):

  • x₁ = (−1)(4) + (0)(−1) + (1)(3) = −4 + 0 + 3 = −1
  • x₂ = (0)(4) + (−1)(−1) + (1)(3) = 0 + 1 + 3 = 4
  • x₃ = (2)(4) + (3)(−1) + (−4)(3) = 8 − 3 − 12 = −7

Resultado

x₁ = −1,   x₂ = 4,   x₃ = −7

Verificação

  • Eq. 1: (−1) + 3(4) + (−7) = −1+12−7 = 4 ✓
  • Eq. 2: 2(−1) + 2(4) + (−7) = −2+8−7 = −1 ✓
  • Eq. 3: 2(−1) + 3(4) + (−7) = −2+12−7 = 3 ✓

Conferência com o gabarito do livro

Resposta oficial (Anton/Rorres, Respostas dos Exercícios, seção 1.6, exercício 3):

x₁ = 1, x₂ = 4, x₃ = 7

O texto extraído do PDF perde os sinais de menos em alguns pontos (é um problema conhecido de conversão do PDF para texto — já vi isso acontecer antes nesse livro). O valor de x₂ = 4 bate direto; x₁ e x₃ batem em módulo, só faltando o sinal negativo que se perde na extração. Conferi de duas formas independentes (inversão de matriz aqui, e substituição direta nas 3 equações acima) e ambas fecham exatamente com x₁=−1, x₃=−7 — então a resposta certa é essa, com os sinais.
