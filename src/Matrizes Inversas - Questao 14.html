Verificação

Multiplicando A pela matriz não-escalada e conferindo que dá 7·I:

  • Linha 1 de A = [1, 2, 0] · colunas → (1·3+2·2+0·(−4), 1·2+2·(−1)+0·2, 1·(−4)+2·2+0·3) = (7, 0, 0) ✓
  • Linha 2 de A = [2, 1, 2] · colunas → (2·3+1·2+2·(−4), 2·2+1·(−1)+2·2, 2·(−4)+1·2+2·3) = (0, 7, 0) ✓
  • Linha 3 de A = [0, 2, 1] · colunas → (0·3+2·2+1·(−4), 0·2+2·(−1)+1·2, 0·(−4)+2·2+1·3) = (0, 0, 7) ✓

Dividindo tudo por 7, confirma A·A⁻¹ = I.
